# Phase 1 gate (2026-11-15)

Gate: "Index pharos + lucene on writer, search on a separate reader against MinIO; same top-10 as single node; a new generation is visible in <= poll interval + download".

**Status: PASSED (run 2026-11-16, gate script exit 0)**

## How to run

```bash
# MinIO server binary (dl.min.io community downloads are retired, HTTP 410; the run below used
# the Homebrew build RELEASE.2025-10-15T17-29-55Z, the last community release)
mvn clean package -DskipTests
MINIO_BIN=/path/to/minio PHAROS_INDEX_HEAP=4g PHAROS_WEB_HEAP=2g \
  systemd-run --user --scope -q -p MemoryMax=10G bash scripts/cluster-gate.sh
```

The script never downloads; without the binary it prints instructions and exits 2. It uses isolated writer/reader homes (`-Duser.home` + `-Dpharos.home`) under `$GATE` (default a temp dir), MinIO on 127.0.0.1:9000, writer web on :7300, reader web on :7301, and reads the lucene path read-only from `~/.pharos/registry.json`. Logging uses `scripts/cluster-gate-logback.xml` (cluster INFO lines are needed by the freshness check). Heaps: `PHAROS_INDEX_HEAP` / `PHAROS_WEB_HEAP` (default `PHAROS_HEAP`, 8g). Exit 0 = gate passed.
