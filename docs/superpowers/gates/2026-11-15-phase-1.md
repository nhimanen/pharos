## How to run

```bash
mkdir -p ~/.cache/pharos-gate && curl -fL -o ~/.cache/pharos-gate/minio https://dl.min.io/server/minio/release/linux-amd64/minio && chmod +x ~/.cache/pharos-gate/minio
mvn clean package -DskipTests
scripts/cluster-gate.sh        # or MINIO_BIN=/path/to/minio scripts/cluster-gate.sh
```

The script never downloads; without the binary it prints the command above and exits 2. It uses isolated writer/reader homes (`-Duser.home` + `-Dpharos.home`) under a temp dir, MinIO on 127.0.0.1:9000, writer web on :7300, reader web on :7301, and reads the lucene path read-only from `~/.pharos/registry.json`. Exit 0 = gate passed.
